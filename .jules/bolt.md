## 2026-10-31 - Avoid sorting cached arrays in place
**Learning:** In `SearchHistoryManager` and similar structures using Maps as in-memory caches, calling `.sort()` directly on retrieved arrays mutates the underlying cache in place. This can lead to bugs where the cache ordering keeps shifting unexpectedly. Additionally, sorting an entire array (O(N log N)) just to find an extremum (like the most recent item) is an anti-pattern when a single O(N) pass would suffice.
**Action:** Always copy cached arrays before sorting (e.g., `[...arr].sort()`) to prevent in-place cache mutation, and use an O(N) pass (like `reduce()`) when finding extremums instead of sorting.
