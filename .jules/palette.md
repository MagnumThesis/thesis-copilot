## 2024-05-24 - AccessibleTooltip Link Wrapping Pattern
**Learning:** When wrapping React Router `<Link>` components in Shadcn/Radix tooltips (`<AccessibleTooltip>`), applying `asChild` to the tooltip trigger is not enough. The intermediate wrapper element (e.g., `<Button>`) must also use `asChild` to prevent hydration errors and invalid DOM nesting (`<button>` inside `<button>`). Furthermore, native `title` attributes on `<Link>` or `<button>` cause redundant overlapping tooltips and must be removed. Finally, `span.sr-only` is inconsistently handled by screen readers in interactive elements; `aria-label` is safer and more robust.
**Action:** Always use the pattern `<AccessibleTooltip><Button asChild aria-label="..."><Link>...</Link></Button></AccessibleTooltip>` for icon-only link buttons, and explicitly strip native `title` attributes and `sr-only` children from the final markup.
